# CoastSat-SuperResolution

This repository contains code used to study whether satellite image super-resolution can improve shoreline extraction with CoastSat. It includes experiments with interpolation, the Zhao method, SRCNN, and DiffPIR.

## Repository contents

- `coastsat/`: code for image processing and shoreline extraction.
- `super_resolution/`: code and models for the super-resolution experiments.
- `classification/models/`: image classification models.
- `examples/`: example data and supporting files.
- `example_jupyter.ipynb`: notebook for running the workflow.

## How to use

1. Download the repository using **Code → Download ZIP**, then extract it.
2. Place the data in the locations indicated in `example_jupyter.ipynb`.
3. Open the notebook, update the local file paths, and run its cells in order.
