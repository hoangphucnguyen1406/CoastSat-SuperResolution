#CoastSat-SuperResolution

This repository contains the code used to study whether satellite image super-resolution can improve shoreline extraction with CoastSat. It includes the CoastSat workflow and experiments with interpolation, the Zhao method, SRCNN, and DiffPIR.

#Repository contents

coastsat/: CoastSat code used for image processing and shoreline extraction.
super_resolution/: code and models for the super-resolution experiments.
classification/models/: models used for image classification.
examples/: example data and supporting files.
example_jupyter.ipynb: notebook for running the workflow.
